# Portafolio - Programacion III (Kotlin / Android / Jetpack Compose)

Gestion 2026 - Docente: Hidalgo Canaviri Johnn Anselmo

Repositorio de material de clase organizado por sesion, a partir del silabo
`FPRE-DR-001_SILABO_PREGRADO_V4.pdf`. Cada carpeta `Sesion-XX` contiene el
detalle de la actividad (antes / en clase / despues), el tema del curso al
que pertenece y una plantilla para los recursos propios del docente.
